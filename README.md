# Conciliador DIAN

Aplicación web para conciliar facturas electrónicas DIAN vs Contabilidad, mes a mes.

## Desarrollo local

```bash
npm install
npm run dev
```

## Deploy en Cloudflare Pages

1. Sube este repo a GitHub
2. Conecta en Cloudflare Pages
3. Build command: `npm run build`
4. Output directory: `dist`
